# Запуск бота

## 1. Создать бота (один раз)
1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя и логин (на `bot`).
2. BotFather выдаст **токен**. Это пароль от бота. **Никому не показывайте, не
   вставляйте в чат, в код и в GitHub.**
3. Если токен всё же засветился: у @BotFather `/revoke` выпустит новый.

## 2. Проверка на своём компьютере (самый простой способ)
```bash
cp .env.example .env        # затем впишите токен в .env (он в .gitignore)
python -m proverka_bot poll # остановить: Ctrl+C
```
Напишите боту в Telegram — он ответит. Пока окно открыто, бот работает.

## 3. Бесплатный хостинг (чтобы работал без вас)
Бот сделан по схеме **webhook**: Telegram сам присылает сообщения на адрес
`https://…/webhook`, поэтому подходит любой хостинг, который запускает
Docker-образ или Python-программу и даёт HTTPS-адрес.

Настройки на хостинге (раздел Environment / Secrets):
| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | токен от BotFather |
| `WEBHOOK_SECRET` | придуманная вами длинная случайная строка (16+ символов: латиница, цифры, `_`, `-`) |
| `URLHAUS_KEY` | *(необязательно)* ключ базы опасных сайтов URLhaus с https://auth.abuse.ch. Без него проверка по базе выключена |

Команда запуска: `python -m proverka_bot serve` (или соберите `Dockerfile`).
Порт хостинг передаёт сам через `PORT`.

Адрес сервиса бот сообщает Telegram **сам при каждом запуске**, если задана
переменная `PUBLIC_URL` (например, `https://имя.onrender.com`). На Render она
подставляется автоматически (`RENDER_EXTERNAL_URL`). Если с вашего компьютера
Telegram недоступен (блокировка, VPN), это удобно: ничего запускать дома не нужно.

Хостинг без автоподстановки адреса: задайте `PUBLIC_URL` вручную. Либо
один раз выполните со своего компьютера
`python -m proverka_bot set-webhook https://ВАШ-АДРЕС`.

### Про «засыпание»
Многие бесплатные хостинги усыпляют сервис без запросов. Для webhook это
терпимо: первое сообщение после паузы может ответить с задержкой (десятки
секунд), Telegram повторит доставку. Условия бесплатных тарифов меняются —
проверяйте их на сайте хостинга.

## Чтение скриншотов
Для распознавания текста на картинках нужна программа Tesseract. Она ставится
через `Dockerfile`, поэтому на хостинге сервис должен запускаться **из Docker**
(на Render: Language = Docker). Без Tesseract бот работает, но на фото отвечает,
что пока не читает картинки. Картинки не сохраняются и никуда не отправляются.

## Безопасность
- Webhook принимает только запросы с верным секретом (`WEBHOOK_SECRET`).
- Токен и секрет не пишутся в логи; сообщения пользователей не сохраняются.
- Бот отвечает только в личных чатах, ограничивает частоту (6 проверок в минуту).
